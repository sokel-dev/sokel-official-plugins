# SearXNG

通过自己部署的开源 SearXNG 元搜索服务查询网页。此连接器不需要 SaaS 搜索订阅或厂商 API 密钥。所选搜索引擎仍需网络访问，部分可选引擎也可能要求各自的账号，请启用适合部署环境的引擎。

## 配置

在插件部署环境中设置 `SOKEL_SEARXNG_URL`，例如 `http://searxng:8080` 或 `https://search.example.org/searxng`。支持 HTTP(S)、内网地址和反向代理路径前缀，没有默认公共地址。URL 不能含认证信息、查询参数或片段。容器中的 `localhost` 指向插件容器，应使用共享服务网络或可访问的主机地址。

在 SearXNG 配置中启用 JSON 响应：

```yaml
search:
  formats:
    - html
    - json
```

修改配置后重新加载实例。403 可能表示未启用 JSON、缺少认证或访问被拒绝；HTML 响应通常来自代理登录页。反爬保护或搜索引擎限制也可能阻止自动调用。

可选的**代理用户名**和**代理密码**支持反向代理层的 HTTP Basic 认证，需同时填写或同时留空。它们不是 SearXNG 账号凭证。凭证仅发往配置的服务。插件不跟随重定向，包括会跳转到外部服务的搜索快捷指令。TLS 验证始终开启；自定义证书应由运行环境信任，而不是关闭校验。

## 操作

| 操作 | 行为 |
| --- | --- |
| 搜索网页 | 必填 `query`；通过可选的 `options` 选择引擎、分类、语言、页码、结果数量、安全搜索和时间范围。 |
| 列出搜索引擎 | 读取实例名称、版本、分类和可用引擎及其支持的功能。 |
| 检查服务健康状态 | 检查 `/healthz`。进程健康不代表 JSON 搜索或外部引擎可用。 |

示例：

```json
{"query":"self hosted document search","options":{"categories":["general"],"language":"en","page":1,"limit":20,"safe_search":1,"time_range":"month"}}
```

`options.page` 从 1 开始，最多 1000。`limit` 范围 1–100，默认 20，仅限制当前上游页面的返回数量。`clipped=true` 表示当前页有部分结果未返回，可以增加数量限制来读取同一页更多结果。插件不会编造总条数或可靠的 `has_more`，因为各引擎的分页能力不同。需要后续页时，应在引擎支持的前提下显式增加页码。

省略 `safe_search` 时保留实例设置；显式传入 0 关闭过滤，1 请求中等过滤，2 请求严格过滤，实际效果取决于引擎是否支持。`time_range` 可填 `day`、`month` 或 `year`。引擎和分类名称来自**列出搜索引擎**，区分大小写。每次最多选择 30 个引擎或分类。查询文本最多 4096 个 UTF-8 字节。

输出包含可用的结果标题、链接、摘要、引擎名称、分类和分数，以及建议、纠错和引擎错误。`partial=true` 表示至少一个引擎失败，但仍返回有效结果。结果为空且存在引擎错误时，不应认为检索对象不存在。分数是上游排序信息，不是校准后的置信度。首版不返回富答案卡片、知识框和媒体专用字段。结果链接和摘要 HTML 仅作为数据返回，插件不会访问链接或执行 HTML。

## 限制和验证

每个 HTTP 请求超时为 60 秒，搜索操作声明 90 秒的工作流超时。响应最多 8 MiB。限流和代理失败会返回错误，不暴露服务原始错误正文，不自动重试。

接口路径和字段已依据 2026-11-04 查阅的 SearXNG 官方文档及源码核对。测试覆盖实际生成的字段绑定、显式零与省略安全搜索的区别、部分结果、当前页截断、配置读取、代理认证和传输边界。搜索样例由上游单元测试数据和响应序列化逻辑派生，不是真实搜索抓包。未对 SearXNG 实例或生产搜索引擎进行实际验收。
