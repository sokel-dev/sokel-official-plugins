# 微信公众号

把文章写进草稿箱、发布、拿到永久链接。**国内唯一一条「API 正经、金融内容可做、覆盖面够」的主渠道。**

## 先看这三条硬门槛

1. **必须是认证的服务号/订阅号**。2025-07 起微信收回了个人主体与未认证企业号的发布接口权限，
   那些账号调用会得到 48001。
2. **调用服务器的公网出口 IP 要在白名单里**，否则一切接口都回 40164。
   后台「设置与开发 → 基本配置 → IP 白名单」。容器部署时这条最容易漏——
   在容器里 `curl ifconfig.me` 查一次真实出口，别猜。
3. **发出的文章不进历史消息流**。`freepublish` 产出的是永久链接，适合「内容沉淀 + 别处引流」，
   **不等于群发**。要群发是另一套接口与另一套限制（每月次数受限）。

## 配置

公众号后台「设置与开发 → 基本配置」拿 **AppID** 与 **AppSecret**（密码只在生成时显示一次，
丢了只能重置，而重置会让旧的立刻失效），填进凭证；再把出口 IP 加进白名单。

点「测试」验证——它会换一次 token 并查草稿数，**一次把三件事都验出来**：
密钥对不对、IP 在不在白名单、账号有没有发布权限。

> ⚠️ **单副本部署**。access_token 是全局唯一的，同一个 AppID 再换一次，上一个立刻作废。
> 多副本会互相顶掉对方的 token（表现是随机 40001）。插件会自动重试一次，但别指望它救多副本。

## 一条流长什么样

```
[封面图] → [上传图片(封面)] ─┐
                              ├→ [建草稿] → [人工审核(可选)] → [发布草稿] → [拿到文章链接]
[正文配图] → [上传图片(正文)] ┘
```

**为什么拆成建草稿 + 发布两步**：草稿建完可以在公众号后台肉眼复核——金融内容该有这个卡点。
画布上要不要接一个人工节点，由你决定；不接的话两步连着跑就是全自动。

## 三个坑，插件已经替你挡在发布之前

**封面图是必填的**，且必须是永久素材的 media_id（用「上传图片」，用途选「封面」）。
不给的话微信回一句语焉不详的 41005。

**正文里的外链图片一律显示不出来**（微信防盗链）。所以图片要先用「上传图片」
（用途选「正文配图」）换成 `mp.weixin.qq.com` 的地址，再拼进 HTML 的 `<img src>`。
插件会在建草稿前扫一遍正文，发现外链图就拦下——否则你会发出一篇没有图的文章。

**发布是异步的**。`submit` 成功只代表任务提交了，还可能卡在原创声明或平台审核上最终失败。
「发布草稿」默认**等到发布完成**才返回，状态会翻译成人话
（success / publishing / original_failed / audit_failed / banned…）。

## 正文 HTML 能写什么

支持基础 HTML（p / h1-h6 / strong / em / ul / ol / blockquote / img / a / table），
**不支持** script、iframe、外部样式表；内联 style 部分生效。
复杂排版建议在别处排好再转成这套受限 HTML。

## 限制

| 项 | 上限 |
|---|---|
| 标题 | 64 字 |
| 摘要 | 120 字（留空则微信截正文前 54 字） |
| 封面图 | 10MB |
| 正文配图 | **1MB**（和封面图不是一个限制） |
| 接口调用 | 按账号有日配额，超了回 45009 |

## 常见错误码

| 码 | 意思 |
|---|---|
| 40164 | IP 不在白名单——最常见的一个 |
| 48001 | 账号没有这个接口权限（多半是未认证/个人号） |
| 40001 | AppSecret 不对，或 token 被别的副本顶掉了 |
| 45009 | 接口调用超频 |
| 53405 | 内容不合规——金融类尤其注意荐股与收益承诺一类的表述 |
