# Threads（Meta）

发帖、发帖串。免费、无按次计费；受众规模是这批海外渠道里最大的之一。

## 配置

1. 到 [Meta 开发者后台](https://developers.facebook.com/apps) 建一个 App，产品里加 **Threads API**；
2. Threads API 设置里把回调地址填成平台的：
   `https://<你的平台域名>/api/v1/credentials/oauth/callback`，
   与环境变量 `THREADS_OAUTH_REDIRECT_URL` **一字不差**；
3. 平台管理员配好：
   ```
   THREADS_OAUTH_CLIENT_ID / THREADS_OAUTH_CLIENT_SECRET
   THREADS_OAUTH_REDIRECT_URL / THREADS_OAUTH_PROXY（连不上时填）
   ```
4. 建凭证 → 点「授权」，作用域是 `threads_basic threads_content_publish`；
5. 点「测试」——它会查账号并**顺带告诉你 24 小时内还能发几条**。

> 授权时平台做了两跳：授权码换到的短令牌只活 1 小时，必须再换成 60 天的长令牌。
> 这一步已经在平台里处理好了；**但 60 天到期后需要人重新授权**（Threads 没有刷新令牌）。

## 操作

| 操作 | 说明 |
|---|---|
| 发帖 | 正文 + 可选媒体 + 回复别人 + 谁能回复。回 `id` 与 `url` |
| 发帖串 | 多段文本首尾相连，第一条可带媒体 |
| 检查凭证 | 令牌有效吗 + **剩余发布额度** |

## 媒体是「让它来拉」，不是上传

Threads 不收上传，它会**自己去下载**你给的地址。所以：

- **绑平台文件即可**——平台在把文件交给插件时会换成带签名的下载地址，公网可达；
- 也可以直接给外部图床的公开链接（「媒体地址」字段）；
- 多个媒体自动变成**轮播**（最多 20 个）；
- 图片 JPEG/PNG、视频 MP4。**Threads 下载不到或格式不对时**，插件会报出它给的原因，
  而不是笼统地说发布失败。

带媒体的帖子，插件会**等 Meta 处理完再发布**。不等的话会随机失败、重试又能成——最难查的那种。

## 限制

| 项 | 上限 |
|---|---|
| 正文 | 500 字符（超了插件提前拦下，并提示用「发帖串」） |
| 媒体 | 20 个/条 |
| 发布 | **250 条 / 24 小时**（滚动窗口，账号级） |

「检查凭证」会把已用/总额度带出来，工作流可以据此决定还发不发。

## 常见问题

**401 / code 190**——多半就是 60 天到期了，重新授权一次。

**权限被拒**——授权时缺 `threads_content_publish`，或这个账号不是 Threads 专业/创作者账号。

**媒体处理失败**——那个地址 Threads 下载不到（内网地址、需要登录、签名已过期），
或格式不支持。错误信息里会带上 Meta 给的原因。

**连不上**——graph.threads.net 在境外，在**凭证**里配出站代理；容器里跑用
`http://host.docker.internal:7897`。
