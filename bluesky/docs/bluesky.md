# Bluesky

发帖、发帖串、删帖。**免费、无审批、无按次计费**——是几个公开社交平台里接入成本最低的一个。

## 配置：两分钟

1. Bluesky 里打开 **设置 → Privacy and Security → App Passwords**，生成一个应用专用密码
   （形如 `xxxx-xxxx-xxxx-xxxx`）。
2. 平台里给本插件建一条凭证：
   - **账号**：完整 handle（如 `acme.bsky.social`）或注册邮箱；
   - **应用专用密码**：上一步生成的那串；
   - **服务地址**：留空即可（自建 PDS 才需要改）；
   - **出站代理**：部署环境连不上 bsky.social 时填，如 `http://127.0.0.1:7897`。
3. 点「测试」验证——它会真去换一次会话，通了才算数。

> **别填登录密码**。应用专用密码可以单独撤销，而且拿不到改密码/删账号这类权限。

## 操作

| 操作 | 说明 |
|---|---|
| 发帖 | 正文 + 可选图片/链接卡片/回复。回 `uri`（at:// 地址）、`cid`、`url`（网页链接） |
| 发帖串 | 多段文本首尾相连，第一段可带图 |
| 删帖 | 只能删自己发的；地址可直接粘 bsky.app 链接 |
| 检查凭证 | 应用密码还有效吗 |

## 正文里的链接、话题、@ 会自动变成可点的

这件事插件替你做了，但有必要知道它为什么值一提：**Bluesky 不会自动识别正文里的 URL**，
必须显式给「富文本标注」（facets），而标注的下标是 **UTF-8 字节偏移**——
一条中英混排的帖子按字符数算下标，链接会整体错位。自己拼接口的人十有八九栽在这儿。

支持的三类：

- **链接**：`https://…`，末尾的中文标点会自动剔掉（「详见 https://x.com/a。」的句号不算链接）；
- **话题**：`#A股`（支持中文）；
- **提及**：`@acme.bsky.social`（要完整 handle）。认不出的 @ 就当普通文本，不会让发布失败。

## 链接卡片

给了链接就自动抓一次目标页的标题/摘要/缩略图，拼成卡片——财经内容十条有八条是
「一句话 + 一个链接」，没有卡片的链接在时间线上就是一串裸 URL。

- 默认用**正文里的第一个链接**；
- 「链接卡片」字段填别的地址 = 用那个；
- 填 `-`（减号）= 不要卡片。

抓不到（目标站挡爬虫、超时）**不会让发布失败**，只是退回纯文本链接。

## 限制（都是 Bluesky 的，不是插件的）

| 项 | 上限 |
|---|---|
| 正文 | 300 个字（按字形算，中文一个字算一个）。超了插件会**在发出去之前**拦下 |
| 图片 | 一条 4 张，每张 ≤2MB |
| 视频 | 本插件暂不支持 |
| 频率 | 每账号每小时 5000 点、每天 35000 点；发一条 3 点（≈每小时 1666 条） |

## 常见问题

**「应用专用密码可能已被撤销」**——去设置里重新生成一个，回来更新凭证。
注意改了账号密码会让所有应用密码失效。

**发帖串断在中间**——已经发出去的那几条**不会回滚**（它们已经在公开时间线上了，
删掉是二次破坏）。错误信息和出参 `uris` 里都有已发出的地址，可以接着串或手工收尾。

**回复没挂在串里**——回复要同时给「根」和「父」，插件已经替你取好了；
如果你是拿 at:// 地址手工拼的，检查一下根是不是整串的第一条而不是被回复的那条。

**连不上**——bsky.social 在境外，在**凭证**里配出站代理（按凭证配，不影响别的出站）。
容器里跑的话地址是 `http://host.docker.internal:7897` 而不是 `127.0.0.1`。
