# Mastodon

发嘟文、发嘟文串、删嘟文。**免费、无审批、无按次计费**，且因为是联邦网络，
你可以选一个与受众契合的实例（中文财经圈常见的几个都行），也可以自建。

## 配置：三分钟

1. 在你的实例里打开 **偏好设置 → 开发 → 新建应用**；
2. 作用域至少勾 `write:statuses`（发嘟）、`write:media`（传图）、`read:accounts`（健康检查）；
3. 建好后进应用详情页，复制**「你的访问令牌」**；
4. 平台里建一条凭证：实例地址（如 `https://mastodon.social`）+ 访问令牌；连不上就填出站代理；
5. 点「测试」——它会真去验一次令牌，通了才算数。

> 改了作用域**必须重新生成令牌**，光改设置对已发出去的令牌无效。症状是发嘟 403。

## 操作

| 操作 | 说明 |
|---|---|
| 发嘟文 | 正文 + CW + 可见性 + 图片/视频 + 投票。回 `id` 与 `url` |
| 发嘟文串 | 多段文本首尾相连，CW 与可见性整串继承 |
| 删嘟文 | 只能删自己发的；id 或嘟文链接都收 |
| 检查凭证 | 令牌还有效吗、作用域够不够 |

## 几条与别家不同的

**字数上限不是 500**。Mastodon 每个实例自己配：mastodon.social 是 500，不少中文实例是
5000、有的到 11000。插件会去问实例（`/api/v2/instance`）并缓存，所以你在网页上能发多长，
这里就能发多长。

**内容警告（CW）**。联邦圈的惯例是敏感或长内容折在 CW 后面，财经观点尤其常见——
填了「内容警告」，正文就会折叠，先显示那一行提示。

**可见性四档**：公开（进公共时间线）/ 不列出（可见但不进公共时间线）/ 仅关注者 / 私信。
嘟文串的后续条目**继承首条**，不会一串里混进两种可见性。

**重试不会发重**。发布带了 Idempotency-Key（一小时内同键只落一条），所以工作流因为网络
抖动重跑一次，不会在时间线上留下两条一样的嘟文。

**视频要等转码**。图片是同步的，视频/音频由实例异步处理——插件会等到处理完再发嘟，
不等的话嘟文会被 422 拒（而错误只说「媒体不可用」）。

## 常见问题

**403**——多半是应用作用域不够（发嘟要 `write:statuses`，传图要 `write:media`），
改完记得重新生成令牌。

**422**——常见是超字数、投票选项不合规、或媒体与投票同时给了（Mastodon 不允许）。

**429**——各实例自己配额度，小实例的额度可能很紧，降低发布频率。

**连不上**——境外实例在国内部署要在**凭证**里配出站代理；容器里跑的话用
`http://host.docker.internal:7897` 而不是 `127.0.0.1`。
