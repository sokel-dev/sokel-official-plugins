# YouTube 字幕

取任意公开 YouTube 视频的字幕，产出**带时间轴的分句**和**拼好的全文**。不需要 YouTube 账号，也不需要 API key。

## 能做什么

- 按语言优先级取字幕（比如「优先中文，没有就英文」）
- 区分**人工字幕**和**机器自动生成**的（质量差别很大，可以只要人工的）
- 用 YouTube 自带的机器翻译把字幕转成别的语言
- 先列出一个视频有哪些字幕可用，再决定取哪条

典型用法：取字幕 → LLM 总结 → 写进数据表 / 发到群里。

## 两个操作

### 取字幕

| 入参 | 说明 |
|---|---|
| **视频** | 视频 id 或任意 YouTube 链接。`watch?v=…`、`youtu.be/…`、Shorts、`embed/…`、直播回放都认，直接粘地址栏里的东西即可 |
| **语言优先级** | 逗号分隔，从高到低，如 `zh-Hans,zh,en`。取第一个命中的；留空 = `en`。**认地区变体**：填 `en` 也能命中 `en-US` / `en-GB`，不必先去查这个视频到底标的哪一种 |
| **字幕类型** | 「都行」（同语言下人工优先）/「只要人工字幕」/「只要自动生成的」 |
| **翻译成** | 填语言代码则用 YouTube 机翻转一遍。**先按优先级选轨，再翻译** |
| **保留格式标记** | 保留 `<b>` `<i>` 之类的内联标签。默认去掉 |

出参里 `全文` 是拼好的一整段（喂给 LLM 用），`分句` 带每句的开始时刻与时长（做时间轴跳转、按时间切片用）。两个都给，是因为这两种用法各占一半，只给一种另一半就得再取一次。

> `覆盖时长` 是最后一句字幕的结束时刻，**不等于视频总长**——片尾常常没有字幕。

### 列可用字幕

给一个视频，列出它有哪些语言的字幕、哪些是人工的、每条能翻译成什么。

典型用法是接一个条件分支：`有人工字幕` 为真就取人工的，否则退回自动生成的。人工字幕排在列表前面。

## 部署与凭证

本插件**不需要 YouTube 账号**。凭证里只有两项，都是为了对付同一件事：

**YouTube 会封机房 IP。** 部署到任何云主机上，早晚会看到「被 YouTube 风控挡下」——返回 429，或者要求「确认你不是机器人」。这不是插件坏了，是你的出口 IP 被认成了爬虫。

解法是在凭证里配一个**住宅代理**：

```
http://用户名:密码@host:端口
socks5://host:1080
```

配完用凭证页的「测试」按钮验一下——它会拿一个公开视频真取一次，能取到就说明出站这条路是通的。

另一项 `User-Agent` 留空即可，只在需要伪装成特定浏览器时才填。

## 取不到的几种情况

插件会直接说明原因，不用猜：

| 提示 | 含义 |
|---|---|
| 这个视频没有开放字幕 | 作者关掉了字幕，或视频刚发还没生成 |
| 没有匹配的字幕 | 报错里会**列出这个视频现有哪些语言**，照着改语言优先级即可。注意地区变体是认的（`en` ↔ `en-US`），会报这个说明确实是另一种语言 |
| 被 YouTube 风控挡下 | 出口 IP 被封，配代理（见上） |
| 有年龄限制 | 需要登录才能看的视频取不到。YouTube 已废弃 cookie 认证那条路，没有绕法 |
| 视频不可用 | id 写错、视频已删除或设为私享 |
| 要求 PO Token | 少数视频的新式校验，目前取不到 |

## 它是怎么做到不用 API key 的

走的是 YouTube 网页客户端自己在用的那套接口（视频页 → player 接口 → 字幕接口），不是 YouTube Data API v3。

顺带说明为什么不走官方 API：那条路要 key、有配额，而且它的 `captions.download` **只能下你自己频道的字幕**，别人的视频一律拒绝——也就是说官方 API 根本做不了这件事。

代价是这套接口未公开，YouTube 改了它就得跟着改。真遇到「找不到 InnerTube key」「player 响应解析失败」这类提示，多半就是它改了，需要更新插件。
