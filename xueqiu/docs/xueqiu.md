# 雪球（非官方接口）

发帖（可带图）+ 检查凭证。

> ⚠️ **雪球没有官方发布 API。** 这个插件调的是它网页端自己在用的接口，属于未授权的自动化：
> 接口随时可能改（改了没有通知，只有发布失败），账号有被限流/封禁的风险。
> 用它只发**你自己的真实内容**、走**你自己账号的额度**、**低频**，并接上失效告警。

## 配置

1. 浏览器登录雪球；
2. F12 → Network → 随便点开一个请求 → 复制**整条 Cookie**（不是某一个键），粘进凭证的「Cookie」；
3. 其余三个字段先留空：
   - **会话令牌**：插件会自己去页面上取；取不到时错误信息会告诉你去哪儿复制；
   - **风控参数**：先不带试；被拦了再把浏览器 URL 上的 `md5__1038=` 那串粘进来；
   - **User-Agent**：留空用常见的桌面 Chrome UA（与你取 cookie 的浏览器一致更稳）；
4. 点「测试」——它打一个**无副作用**的登录态接口，不会在你时间线上留下任何东西。

**Cookie 会过期。** 配一条工作流：定时「检查凭证」→ 失效则通知 + 人工待办（去重新登录）→
把新 Cookie 用「更新凭证」写回。这条链路平台已经现成（凭证要先打开「允许工作流改写」）。

## 两种发法：短帖 vs 长文

| | 发帖（短帖） | **写长文（存草稿）** |
|---|---|---|
| 去哪 | 时间线，一句话观点 | 专栏，投研内容的主场 |
| 产出 | **直接发布** | **草稿**——最后一步在网页上点发布 |
| 需要 | `session_token`（插件自动取，取不到要你粘一次） | **什么都不用**，最省心 |
| 风控参数 | 可能需要 | 没见过 |

**要稳就用长文。** 它那套接口干净得多，而且「自动写、人工发」在合规上也更稳。

## 发帖

正文给**纯文本或简单 markdown**即可，插件转成雪球的 HTML：

- 空行/换行分段 → `<p>`；
- `**加粗**` → `<b>`；
- 正文里的链接自动包成可点的 `<a>`；
- 已经是 HTML（含 `<p>`/`<div>` 等）则**原样透传**，不二次加工；
- 图片：先传到雪球图床，再按它的固定形状嵌在文末。

### AI 披露（`ai_disclose`）

雪球的发帖参数里有这个字段。**内容经 LLM 改写或生成过就把它打开**——这是平台的合规要求，
插件把它做成显式开关而不是替你写死 0。

## 常见问题

**「Cookie 过期了」**——重新登录一次，更新凭证里的 Cookie。

**「被风控拦了」（回的是一页 HTML 而不是 JSON）**——把浏览器请求 URL 上的
`md5__1038=` 整串值粘进凭证的「风控参数」再试。

**「没能取到 session_token」**——在浏览器里手动发一条帖子，F12 → Network → `update.json`
→ 请求体里复制 `session_token` 的值，粘进凭证同名字段。

**「发出去了但没认出帖子 id」/「没认出图片地址」**——雪球改了应答形状。
把那次的应答贴给开发者，改一行就能跟上（插件用的是宽松提取，不是钉死键名）。

## 没做的

- **一键发布长文**（`save.json` 的语义就是存草稿；发布那一步要你在网页上点，这也是有意的）；
- **评论/转发**；
- **删帖**——发错了去网页上删，比在这里多做一个能误删的操作安全。
