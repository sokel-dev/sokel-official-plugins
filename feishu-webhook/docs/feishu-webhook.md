# 飞书群机器人（webhook）

往**一个飞书群**里发消息的最短路径：不用建应用、不用找管理员，30 秒配好。
适合告警推送、日报通知这类「只发不收」的场景。要收消息触发工作流、发给任意人、
写文档/多维表格，用「飞书」主插件（自建应用）。

## 配置（30 秒）

1. 打开目标群 → 设置 → **群机器人** → 添加机器人 → **自定义机器人**。
2. 复制 **webhook 地址**（`https://open.feishu.cn/open-apis/bot/v2/hook/…`）→
   粘进本插件凭证。
3. 建议顺手开**签名校验**（安全设置里），把密钥也粘进凭证——不开的话拿到这条
   URL 的任何人都能往你们群里发消息。

一条凭证 = 一个群的一个机器人。要发多个群就各建一条凭证。

## 用法

`webhook_send` 三种内容三选一（都填时卡片 > Markdown > 文本）：

- **文本**：可勾「@所有人」。
- **Markdown**：以卡片渲染，支持 **加粗**、[链接](…)、列表、代码块，可带标题。
  告警和报告用它。
- **卡片 JSON**：在飞书[卡片搭建工具](https://open.feishu.cn/cardkit)拼好后粘进来。
  注意：webhook 机器人的卡片**按钮点击不会回到工作流**（它收不了消息），
  要交互用主插件。

## 限制（飞书定的）

- 只能发到添加机器人的**那一个群**；
- 收不了消息、不能私聊、@不到具体的人（只能@所有人）；
- 频控 100 条/分钟，超了报 9499。

## 排错

| 报错 | 处理 |
|---|---|
| 签名校验失败（19021） | 机器人开了签名但凭证里密钥不对/没填 |
| 触发频控（9499） | 降低发送频率（100 条/分钟） |
| 地址不像飞书群机器人的 | webhook URL 粘错了，重新从群设置里复制 |
