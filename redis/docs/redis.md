# Redis

把 Redis 当**工作流的共享内存**：跨运行的计数器、去重集合、状态标记、队列、排行榜，
以及和外部系统之间的一条实时消息通道。自建实例与云托管（阿里云/腾讯云 Redis、
Upstash…）都一样，凭证里填地址即可。

## 一、准备凭证

| 字段 | 怎么填 |
|---|---|
| 地址 | `host:port`，如 `redis.internal:6379`。**插件进程要连得到它**——云实例记得把插件所在机器的公网 IP 加进白名单 |
| 用户名 | Redis 6+ 的 ACL 用户；用传统 `requirepass` 密码就留空 |
| 密码 | 没设就留空 |
| 库号 | 默认 0。**集群模式只有 0 号库** |
| TLS | 内网明文用 `off`；云托管开了加密用 `on`；自签证书用 `on_insecure`（仍加密，但不校验证书） |

配好点「检查凭证」：通了会显示版本、部署形态、已用内存与当前库的键数。

## 二、挑哪个操作

| 想做的事 | 用 | 关键出参 |
|---|---|---|
| 存/取一个值 | 存值 / 取值 | `exists`（未命中不是错误）|
| 幂等闸、简易锁 | 存值 + 写入条件「仅当键不存在」 | `ok=true` 才是抢到 |
| 计数、限流、发号 | 自增计数 | `value`（原子，并发不丢）|
| 判断「这条见过没有」 | 集合添加 | `added=0` 就是见过了 |
| 对象型状态 | 写哈希 / 取哈希 | `fields` |
| 队列 | 入列表 + 出列表（右入左出＝先进先出）| 队列空回 0 条 |
| 排行榜 / 优先级 / 时间窗 | 排行榜写入 + 排行榜取段 | Top10＝起始 0、取 10 名、分数从高到低 |
| 找一批键 | 扫键（**别用 KEYS**）| `cursor` 传回来接着扫，`done=true` 才扫完 |
| 上面没有的命令 | 通用命令 | 命令名 + 参数按官方文档顺序 |

## 三、收消息触发工作流

凭证里填「事件盯哪些频道」或「事件盯哪些 Stream」（**填了才启动事件源**），
然后在工作流里用**事件触发器**选对应事件。两条路的区别是**丢不丢得起**：

| | Pub/Sub（频道）| Stream |
|---|---|---|
| 留存 | 不留存，发完即弃 | 留存，可回溯 |
| 插件断线期间的消息 | **收不到** | 补得回（按 id 续读）|
| 消息 id | 没有 | 有，唯一且递增 |
| 适合 | 实时信号：缓存失效、重新加载 | 不能丢的任务：订单、告警、待办 |

频道支持通配（`orders.*`）。Stream 从**接上的那一刻**开始读，不回溯历史——
接一个有积压的老 Stream 不会把历史全灌成工作流运行。

要从工作流这边发消息，用「发布消息」（Pub/Sub）或「写入 Stream」。

## 四、坑

- **「不存在」不是错误**：取值未命中回 `exists=false`、出列表队列空回 0 条、
  「仅当不存在」没抢到回 `ok=false`。用条件节点判这些出参，别指望它报错走失败分支。
- **设过期只能给正数**：Redis 收到 0 或负数会**当场删键**。插件把这个挡住了，
  真要删请用「删键」。
- **写入尽量带上限**：存值的过期秒数、写入 Stream 的保留条数上限。不带上限的键只增不减，
  内存满了 Redis 会开始拒写，或按淘汰策略删掉你没打算删的东西。
- **值都是字符串**：写进去的数字、布尔取出来都是字符串（Redis 本身如此），要当数字用就转一次。
- **别在生产库上用 KEYS**：Redis 单线程，KEYS 会把整个实例卡住。扫键是增量的，安全。
- **集群模式**：只有 0 号库；一次删多个键这类跨槽位命令可能被拒——拆成单键做。
