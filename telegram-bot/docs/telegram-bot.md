# Telegram Bot

把 Telegram 机器人接进工作流：收消息触发、发消息/图片/文件、下载用户发来的附件，
也可以直调任意 Bot API 方法。

## 申请凭证

1. Telegram 里找 **@BotFather** → `/newbot` → 起名字 → 它会给你一串
   **Bot Token**（形如 `123456789:AAH...`）
2. 平台「凭证」里新建一条，把 token 填进去，只有这一项

填完点凭证行的 **「检查」**：它调一次 `getMe`（不发消息），回的 bot 用户名能认出
这条凭证到底是测试 bot 还是正式 bot——两串 token 长得一模一样。

## 收消息（事件触发）

拖「插件事件」触发器、插件选它、勾选「收到消息」即可。**不需要配 webhook**——
插件用长轮询取更新，所以平台不必有公网地址。

多个 bot 就建多条凭证：事件里带着 `credential_id`（是哪个 bot 收到的），
下游发消息时把凭证绑到这个变量上，多 bot 就天然回对了人。

## 注意

- **Bot 看不到群里的普通消息**，除非关掉隐私模式：BotFather → `/setprivacy` → Disable。
  这是「群里说话机器人没反应」的头号原因。
- 用户必须**先给 bot 发一句话**（或把它拉进群），bot 才能给他发消息——Telegram 不允许主动搭讪。
- 下载附件走 Bot API，**上限 20MB**；更大的文件 Telegram 不给 bot 下。
- 平台在境内时 Telegram 需要代理，见部署文档。
