# Gmail

读写你的 Gmail：列邮件 / 读邮件 / 发邮件，并可作为**事件源**——收到新邮件时触发工作流。

## 授权（不用手填任何密钥）

这个插件走 **OAuth 协作式授权**，不需要你去找 API Key：

1. 在「凭证」里新建一条 Gmail 凭证（三个字段都**留空**——它们由平台自动填写）
2. 保存后点该凭证行的 **「授权」**，浏览器会跳到 Google 的同意页
3. 用要接入的那个 Gmail 账号登录并同意，页面会自动关闭，凭证状态变为已授权

`access_token` / `refresh_token` / `history_id` 三项都是平台维护的，**手填只会把它弄坏**。
令牌过期由平台自动刷新，不需要你定期重新授权。

凭证行的 **「检查」** 会去读一次账号信息，回的是「授权是否还有效 + 授的是哪个邮箱」——
授权授到了另一个 Google 账号是最常见的一种错，看这里的邮箱地址就能认出来。

## 平台在境内时

Google 的授权与 API 都在境外。平台连不上时，授权会**静默卡在弹窗上**（这是实际踩过的坑）。
部署时给平台配 `GOOGLE_OAUTH_PROXY`，见部署文档。

## 新邮件事件

- 事件源按凭证分片：**一个凭证 = 一个 Gmail 账号 = 一路轮询**，多账号就建多条凭证。
- 游标（`history_id`）由事件源自己维护；第一次启动只从「当下」开始，不会把历史邮件洗一遍。
- 事件只带元信息与正文摘要；要附件请在下游用「读邮件」按 `message_id` 取。

## 注意

- 发信的发件人恒为**授权的那个账号**，不能伪造 From。
- 「列邮件」的搜索条件用的是 Gmail 的查询语法（`is:unread from:boss@x.com newer_than:7d`），
  与网页版搜索框完全一致。
