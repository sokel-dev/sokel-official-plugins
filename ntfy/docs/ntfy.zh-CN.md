# ntfy

通过自己的 ntfy 服务发送工作流通知、读取缓存消息。不需要 ntfy.sh 账号、SaaS 订阅、Firebase 项目或云 API 密钥。插件始终发送 `Firebase: no`。

## 配置

1. 运行插件可访问的 ntfy 服务。本地验收使用官方 `binwiederhier/ntfy:v2.37.1` 镜像。连接器使用 HTTP API，不调用 ntfy 命令行客户端。
2. 在插件部署环境中设置 `SOKEL_NTFY_URL`，例如 `http://ntfy:80` 或 `https://notify.example.org/ntfy`。没有默认地址，也不会回退到公共服务。支持 HTTP、HTTPS、内网主机和反向代理路径前缀。地址不能含用户名密码、查询参数或片段。
3. 如果主题受保护，填写可选的**访问令牌**，通过自己服务的账号工具创建。此连接器支持 Bearer 令牌，不支持用户名密码认证。仅当服务允许匿名访问所选主题时留空。

插件容器中的 `localhost` 指向容器本身。请让插件与服务共享网络，或使用插件可访问的地址。跨不可信网络使用 HTTPS；自定义证书必须受运行环境信任，插件不会关闭证书校验，也不会跟随重定向。

## 操作

| 操作 | 输入和行为 |
| --- | --- |
| 检查服务健康状态 | 读取 `/v1/health`，返回 `healthy`。不验证主题访问权限。 |
| 发布通知 | 必填 `topic` 和 `message`；可选 `options.title`、`priority`（1–5）、`tags`、`click`、`cache`。返回服务生成的消息 ID、时间戳和可用元数据。 |
| 轮询缓存通知 | 必填 `topic`；可选 `since`、`cursor`、`limit`。返回 `messages`、`next_cursor`、`has_more`。读完当前缓存后请求即结束。 |

主题名称包含 1–64 个 ASCII 字母、数字、下划线或连字符。正文最多 4096 个 UTF-8 字节，标题最多 512 字节，最多 20 个标签且每个最多 64 字节。`click` 是客户端显示的 HTTP(S) 链接，插件不会访问。未提供邮件或短信转发、附件上传、定时通知、通知操作按钮。收到的附件仅返回元数据，不下载文件。

发布示例：

```json
{"topic":"workflow-alerts","message":"Report is ready","options":{"title":"Daily report","priority":3,"tags":["white_check_mark"],"cache":true}}
```

## 轮询和投递

首次请求的 `since` 支持正数 Unix 时间戳（不超过 9999999999）、`10m` 等时长或 `all`，省略时为 `all`。不接受服务原生消息 ID：ntfy 按消息 ID 续读时，可能重播同一秒内较早的消息。

`limit` 默认 100，范围 1–1000；零也使用默认值。对同一主题续读时，将 `next_cursor` 作为 `cursor` 输入，并省略 `since`。`has_more=true` 时立即继续请求。处理完返回消息后保存游标，即使已经读完当前缓存也应保留；空轮询不会改变游标。不透明游标记录边界时间戳和该秒已交付的消息 ID，因此能过滤上游重复消息，同时保留同一秒内新出现的 ID。消息按时间戳和 ID 排序；同秒 ID 顺序不代表发布顺序。不要修改游标。单秒最多保留 4096 个 ID，更高吞吐量需要拆分主题或使用持久队列。响应截断、游标或消息流无效时操作失败，不推进游标。

发布成功只是服务接受请求，不代表设备收到或已经持久保存。这是尽力读取缓存的工具，不是持久事件队列，也不会自动触发工作流。缓存过期、禁用缓存、时间戳早于已推进边界的延迟消息，以及服务时钟回退，都可能导致消息无法读取。空轮询应保留相同游标稍后重试，而不是重新发布。首次读取高流量主题时，使用有限时间窗口，不要直接读取 `all`。

HTTP 请求超时为 60 秒，响应最多 8 MiB。不自动重试写入；重新发布可能生成第二条通知。遇到 HTTP 429 时操作失败，由工作流稍后处理。

需要完全本地运行时，还应关闭 ntfy 服务端的上游转发和外部 Web Push 端点，使用网页端或支持的 Android 客户端。iOS 即时推送可能需要外部中继和 Apple 推送基础设施；仅自托管服务端并不意味着该链路可离线。此插件不需要 SearXNG 或其他网络工具。

## 验证

协议和实际生成分发测试覆盖认证、Unicode 输入、显式 `cache=false`、HTTP 错误、响应大小、轮询和游标处理。还使用合成主题，在独立的 ntfy 2.37.1 容器上验证了健康检查、发布、同秒去重和继续分页。这不代表已经安装到平台或验证生产设备投递。插件尚未发布。
