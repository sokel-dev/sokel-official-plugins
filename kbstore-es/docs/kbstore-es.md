# 知识库存储（Elasticsearch）

知识库的存储与检索后端：写入分块、向量检索、BM25、混合检索（RRF 融合）。

## 凭证

- **Elasticsearch 地址**：如 `https://es.example.com:9200`
- **API Key**（选填）：ES 开了鉴权时填
- **索引命名空间**：默认 `sokel`，多个环境共用一套 ES 时用它隔开

## 注意

- 建议 **ES 8.x**：混合检索用到的 `knn` 与 RRF 在 8.x 才完整。
- **换嵌入模型必须重建索引**：新旧向量不在同一空间，混着检索的结果会莫名其妙地差。
- 单次写入的分块数有上限（受消息大小限制），插件已自动分批——
  但如果你自己拼很大的批次调它，仍可能撞上限。
