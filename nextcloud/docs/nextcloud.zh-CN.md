# Nextcloud

通过需要认证的 WebDAV API 读写自托管 Nextcloud 文件，无需 SaaS 账户。文件可以保留在自己的基础设施内；外部存储挂载、分享服务及服务器应用可能有各自的外部依赖。本插件不安装 Nextcloud，不配置外部存储，也不开启公开分享。Nextcloud Server 采用 AGPL-3.0 许可。

## 配置连接

将部署变量 `SOKEL_NEXTCLOUD_URL` 设置为实例根地址，例如 `http://nextcloud` 或 `https://files.example.org/cloud`。不要包含 `/remote.php/dav`、凭证、查询参数或片段。支持内网 HTTP 及反向代理路径前缀，没有公共地址回退。容器中的 `localhost` 指该容器自身。

将规范的**用户 ID**和个人安全设置中创建的**应用密码**保存为插件凭证。用户 ID 应采用账户 WebDAV 地址中显示的值，不是显示名称或邮箱登录别名。请求通过 HTTP Basic 认证访问 `/remote.php/dav/files/{user_id}/`。双因素认证或外部登录时尤其适合使用应用密码。插件只拥有该账户的权限。

使用**获取文件或文件夹信息**并留空路径，可进行只读连接检查。实现依据 server 33 的基础 WebDAV 文档，当前手册也记录了相同的基础 API。已有协议和生成分发层夹具测试，**尚未完成真实 Nextcloud 部署验收**；不承诺最低支持版本或对所有服务器版本的完整兼容。

## 操作

| 操作 | 行为 |
| --- | --- |
| 获取文件或文件夹信息 | `PROPFIND Depth: 0`；返回路径、名称、是否目录，以及可用的文件 ID、ETag、大小、类型和修改时间。空路径表示用户文件根目录。 |
| 列出目录 | `PROPFIND Depth: 1`；返回目录本身及直接子项。空路径表示根目录。 |
| 创建目录 | `MKCOL`；创建单层文件夹，父目录必须已经存在。 |
| 上传文件 | 读取原生平台文件，通过 `PUT` 写入目标路径。返回是否创建新文件，以及响应中可用的 ETag。 |
| 下载文件 | 先确认路径是文件，再获取字节并存入平台文件存储，供后续工作流使用。元数据提供强 ETag 时，会附加匹配条件。 |
| 移动文件或目录 | 在同一账户、同一实例内执行 `MOVE`。目标不能已存在，父目录必须存在。可选预期 ETag 用于保护源文件免受并发修改影响。 |

文件 ID 和 ETag 保持字符串，不转换为工作流数字。获取失败的可选 WebDAV 属性会被省略；资源类型属性失败则报错。不会仅凭 207 多状态响应就认为所有条目均成功。

## 路径、文件与覆盖保护

路径相对于用户文件根目录，例如 `Reports/weekly report.pdf`。允许单个首尾斜线。空格、Unicode、`#` 和 `?` 由插件编码。请提供**未编码的路径**，不要传网址。本版本不支持字面百分号（包括百分号转义）、反斜线、控制字符、连续斜线以及 `.`/`..` 路径段。根目录只可用于查询信息和列目录。规范用户 ID 不能包含 `/`、`\\`、`%`、控制字符或 `:`。

上传接受原生平台文件引用或内联字节，**不接受任意下载网址**。上传和下载单文件均限制为 32 MiB。空文件可通过有效的平台文件 ID 传入。目标文件名由 `path` 决定，无需与输入文件名相同。下载时的可选输出文件名必须是不含目录的名称，最多 255 个 UTF-8 字节；默认采用源文件名。

上传默认 `overwrite=false`，发送 `If-None-Match: *`。目标已存在时请求失败，不会覆盖。要替换已有文件，必须显式设置 `overwrite=true`。需要并发保护时，同时将元数据返回的带引号强 ETag（例如 `"a1b2c3"`）原样传给 `if_match`。未开启覆盖时填写 `if_match` 会被拒绝。开启覆盖但不传 ETag，会直接替换当前目标，不检查期间是否有人修改。

移动始终发送 `Overwrite: F`，不会悄悄替换已有目标。禁止移动根目录、移动到自身路径，以及将目录移入自身子目录。预期 ETag 不接受弱 ETag 或通配符。

## 限制与失败处理

列目录只发起一次请求，不虚构偏移量分页。最多接受 2000 个直接子项和 8 MiB XML；超限或格式异常会报错，不返回不完整列表。响应资源网址必须属于配置的服务源站及当前用户文件树；这些网址只作为元数据解析，不会被当成任意下载地址抓取。

HTTP 客户端超时为 120 秒；查询、建目录和移动操作的 SDK 截止时间为 60 秒，文件传输为 180 秒。禁用重定向和自动写入重试。HTTP 412 表示目标已存在或 ETag 条件失败；HTTP 423 表示资源被锁定。错误不包含服务器原始响应体和凭证值。写入超时后先检查当前文件状态，再决定是否重试。下载后若平台存储失败，不会返回文件输出。

本版本不提供分块上传、公开分享、回收站或删除、递归列目录、搜索、分享管理及跨账户移动。协议测试不代表服务已部署、镜像可用或市场版本已经发布。
