# SUBMAIL 赛邮短信

通过 SUBMAIL（赛邮云通信）发**国内短信**与**国际短信**：告警通知、验证码、运营触达。

## 一、准备凭证

1. [SUBMAIL 控制台](https://www.mysubmail.com/console) → 应用集成 → 创建应用。
   **国内「短信」与「国际短信」是两个应用**，各有一对 AppID/AppKey——用哪个建哪个。
2. 把 AppID/AppKey 填进本插件凭证的对应组（只用一边就只填一边）。
3. 国内短信先把**签名**（如【某某科技】）在控制台报备；模板发送再把**模板**提审。
4. 应用若开了 IP 白名单，把插件出口 IP 加进去（或关掉白名单）。

## 二、操作速查

| 操作 | 用途 |
|---|---|
| 国内短信·发送 | 全文直发，内容**必须带已报备的【签名】**；多号码逗号分隔 |
| 国内短信·模板发送 | 模板 ID + 变量（`{"code":"123456"}`）；验证码/通知类推荐——审核快、到达稳 |
| 国际短信·发送 / 模板发送 | 号码带 `+国家码`（+81…、+1…）；用国际短信应用 |
| 查余额 | 国内（条数）与国际（金额）**各查各的**，配了哪组查哪边；定时查 → 低于阈值发告警 |

## 三、短信没收到怎么查

发送操作返回成功（有 send_id）只代表 SUBMAIL **收单**了；到没到手机要看下发状态：

1. 用「国内短信·查发送状态」填 send_id（或手机号）——
   `delivered`=已送达，`dropped`=运营商丢弃（report 字段里有原因），`sending`=在途。
2. dropped 的常见原因：**签名未报备**（内容里的【签名】必须与控制台审核通过的一字不差）、
   内容触发风控（链接/营销词）、空号或黑名单。
3. 新账号资质未审核通过时，只能发到控制台绑定的测试号码。
4. 都正常的话翻一下手机的骚扰拦截箱。

国际短信没有对应查询接口，到达状态在 SUBMAIL 控制台看。

## 四、常用组合

- **告警短信**：告警事件 → 国内短信·模板发送（值班模板 + 变量）。
- **余额巡检**：每天 9 点 → 查余额 → `balance < 100` → 发飞书提醒充值。
- **海外用户通知**：条件节点按国家码分流 → 国内/国际短信各走各的。

## 五、排错

| 报错 | 处理 |
|---|---|
| 不认这对 appid/appkey | 国内与国际是**两个应用**，别把国内的钥匙填进国际组 |
| 内容缺短信签名 | 内容开头加已报备的【签名】 |
| 模板不存在或未过审 | 模板要审核通过才能用；核对模板 ID |
| IP 不在白名单 | 控制台该应用设置里加插件出口 IP |
| 余额不足 | 充值；建议配「余额巡检」工作流 |

## 六、安全

AppKey 只在插件内部使用，不进节点入参/输出/日志。短信是按条计费的出口，
建议给发送类节点接人工审批（对外群发前过一道人）。
