# Discord

往频道发消息。**免费、无审批**，建一个 Webhook 只要频道管理员点几下。

> **定位**：社群分发，不是公开发现渠道。发进去的内容只有频道成员看得到——
> 「研报出来推一条到投研群」用它；要公开曝光用 Bluesky / Mastodon / X。

## 配置：一分钟

1. 频道 → **设置 → 整合 → Webhook → 新建 Webhook**，选好频道；
2. 复制那条 `https://discord.com/api/webhooks/<id>/<token>` 的地址；
3. 平台里建凭证，把它填进「Webhook 地址」。**它本身就是凭据**（拿到就能发消息），按密钥保管；
4. 点「测试」——它会查一次这个 Webhook 是否还在，**不会在群里发测试消息**。

## 操作

| 操作 | 说明 |
|---|---|
| 发消息 | 正文 + 嵌入卡片 + 附件。回消息 id 与链接 |
| 删消息 | 删本 Webhook 自己发的 |
| 检查凭证 | Webhook 还在吗 |

## 卡片怎么用

财经推送是「标题 + 摘要 + 链接 + 几个关键数字」，裸文本在群里刷屏且不好读。填了标题就带卡片：

- **卡片标题 / 卡片链接**：点标题跳去原文；
- **卡片正文**：上限 4096 字符（比正文的 2000 宽得多，长摘要放这里）；
- **卡片字段**：键值对，如 `{"标的":"600519","评级":"买入","目标价":"1800"}`，在卡片里排成两列（按键名排序，同样的输入每次排版一致）；
- **色条**：`#2b6cb0` 这类十六进制，可以按「买入/中性/卖出」给不同颜色；
- **页脚**：常放来源与时间。

## 限制

| 项 | 上限 |
|---|---|
| 正文 | 2000 字符（超了插件会提前拦下，并提示把长内容放进卡片正文） |
| 卡片正文 | 4096 字符 |
| 频率 | 同一个 Webhook 每 2 秒最多 5 条 |

## 常见问题

**404**——Webhook 被频道管理员删了。重新建一个并更新凭证。

**429**——发太快了。合并消息或拉长间隔。

**发进话题（论坛频道）**——填「发进某个话题」的 thread id；删消息时也要给同一个 thread id，
否则 Discord 找不到那条消息。

**连不上**——discord.com 在境外，在**凭证**里配出站代理；容器里跑用
`http://host.docker.internal:7897`。
